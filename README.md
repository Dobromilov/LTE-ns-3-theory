# ns-3 и LTE — база знаний

Статический сайт для совместного изучения ns-3. Сейчас доступны три материала: назначение ns-3, структура проекта ns-3.45 и вводный обзор модуля LTE.

## Структура

```text
docs/
  index.html                 # оболочка страницы и подключения статей
  content/
    outline.js               # разделы и порядок пунктов меню
    intro.js                 # отдельная статья
    architecture.js           # структура проекта
    lte-intro.js               # обзор модуля LTE
  assets/
    styles.css               # оформление
    content-helpers.js       # блоки кода, таблицы, схемы и ссылки на файлы
    app.js                   # навигация и интерактивные демонстрации
templates/
  chapter.js                 # образец новой статьи
CONTRIBUTING.md              # правила добавления материалов
```

Серверная часть, установка пакетов и сборка не требуются. Нет аккаунтов, персонального прогресса и браузерных заметок. Общие изменения — это коммиты в репозиторий; сайт не редактирует файлы через браузер.
